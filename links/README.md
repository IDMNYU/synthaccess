# links

#### links

Links to some other folks doing important work in music technology and access:

- [BLIND ENVY](https://www.youtube.com/watch?v=o2Ow_qP7kjI) - Calvin Van Zytveld and Lemon Guo
- [Low Vision Music](https://www.lowvisionmusic.info/) - Nicholas Spinelli's guides for music technology equipment
- [Flo Tools](https://flotools.org/Flo%20Tools/) - Chi Kim and Rocco Fiorentino's accessibility software for Avid Pro Tools
- [Maxess](https://www.if-tah.com/devices/maxess/) - Iftah Gabbai's collection of accessibility-related externals for Max/MSP
- [Braille Forward](https://www.brailleforward.org/) - Mountain Lakes Public Library Makerspace, New Jersey
- [Sound Without Sight](https://soundwithoutsight.org/)
- [RAMPD](https://rampd.org/) - Recording Artists and Music Professionals With Disabilities
- [MASSIG](https://midi.org/the-music-accessibility-standard-special-interest-group-massig) - the MIDI Association Working Group on Accessibility Standards
